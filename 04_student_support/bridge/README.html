Foundation Bridge — B0 to B4

These five micro-lessons repair prerequisites identified by the ungraded diagnostic. They are support, not assessed work: no points are attached, no file is submitted to the LMS, and using a recovery answer does not cap a grade.

Complete only the units selected by your diagnostic. Each unit is timeboxed to 30 minutes: approximately five minutes for the lesson and worked example, 20 minutes for practice, and five minutes for the exit check and recovery. The maximum workload for all five units is 150 minutes (2h30).

Unit Repair target Diagnostic checks Timebox
B0 — Environment and notebook discipline Environment identity, paths, seeds, clean execution D1–D3 30 min
B1 — Python for experiments Functions, contracts, edge cases, deterministic inputs D4 30 min
B2 — Arrays and dataframes Shape, types, missingness, dated rows, copies, future-availability risks D5–D6 30 min
B3 — Evaluation and leakage Basic probability, temporal roles, rolling origins, controlled policy comparison D7P, D7–D10 30 min
B4 — Evidence and technical writing Narrow claims and claim-to-artifact trace D11–D12 30 min

How to use a unit

  1. Start a 30-minute timer and work without hiding an environment error.
  2. Read the lesson and run or trace the worked micro-example.
  3. Attempt the practice before opening the recovery answer.
  4. Use the exit check to decide Independent, Supported, or Not yet.
  5. If still Not yet, send the earliest failure with ../templates/HELP_REQUEST.md; do not repeat the entire bridge blindly.

Recovery answers demonstrate one acceptable route, not a model submission. Delete or retain your scratch work as you prefer; it is not collected.

The two just-in-time topic refreshers in the parent support folder are separate from this prerequisite bridge. Use them before TD1 or TD3 only when the newly taught Time Series or RL notation is not yet retrievable.
