# Ungraded diagnostic — Time-Series/RL readiness

**Status:** formative and ungraded. Estimated independent work is 45–75
minutes; it is not part of the 18 practical contact hours.

The diagnostic checks the verified environment, temporal dataframe handling,
basic probability, MAE/sMAPE interpretation, chronological boundaries, and a
one-step Bellman target. It does not test ETS, SARIMA, or Q-learning before
those topics are taught.

From the course root run `uv sync --frozen`, then choose the Support or Core
diagnostic starter. Use only the bridge units indicated by the result.
